# Comparing Retrieval Methods for Academic Advisor Discovery

A systematic evaluation of six information retrieval methods for the task of
ranking CS faculty members by relevance to a graduate applicant's research
interest statement.

**Category:** cs.IR — Biraj Subedi (2026)
**Paper:** [`docs/research_paper.tex`](docs/research_paper.tex)
**Web explorer:** [`app/index.html`](app/index.html)

---

## Key Results

| Method | NDCG@10 (Q1) | MAP@10 (Q1) | Mean NDCG@10 (5 queries) |
|--------|-------------|------------|--------------------------|
| **Reranked** | 0.5581 | 0.3463 | **0.477** |
| Semantic | **0.5934** | 0.3877 | 0.450 |
| Hybrid | 0.3469 | 0.1733 | 0.421 |
| BM25 | 0.4537 | 0.2750 | 0.406 |
| LTR | 0.5679 | **0.4800** | — (Q1 only) |
| Jaccard | 0.1396 | 0.0665 | 0.303 |
| TF-IDF | 0.0948 | 0.0250 | 0.246 |
| *Oracle* | *1.000* | — | — |
| *Random* | *0.027* | — | — |

**Across 5 queries:** Reranked achieves the highest mean NDCG@10 (0.477),
followed by Semantic (0.450). After Bonferroni correction across all 15
pairwise comparisons, **TF-IDF is significantly worse than BM25, Semantic,
Hybrid, and Reranked** (p\_Bonf < 0.001 for all four). No other pair is
statistically distinguishable at 5 queries.

**Single-query Q1 (67 labels):** Semantic leads on Q1 (0.593). No pairwise
difference survives Bonferroni correction at n=67 labels alone.

**Field ablation (Q1):** Removing biography drops NDCG by 0.130 (22%).
Research area tags alone score 0.427 — biography is the dominant field.

**arXiv experiment (controlled, 296-professor subpopulation):**
Concatenating paper abstracts *reduces* NDCG from 0.772 → 0.596 (Δ = −0.176).
Relevant professors suffer larger drops than irrelevant ones (−0.238 vs −0.139),
supporting a jargon-dilution explanation.

## Dataset

| Stat | Value |
|------|-------|
| Universities | 9 US CS departments |
| Professors | 768 |
| Relevance judgments | 162 graded (grade 0/1/2) across 5 queries |
| Queries | 5 (Web IR, CV/Robotics, Security, Systems, Bio/Health) |
| arXiv papers fetched | 349 across 296 professors (79 with papers) |

**Evaluation collection** — released openly:
- `data/final/relevance_labels.json` — 67 labels for Q1 (Web IR & NLP)
- `data/final/multi_query_labels.json` — 95 labels for Q2–Q5

**Hybrid weight provenance:** weights (0.35/0.65 and 0.15/0.20/0.65) were
set *a priori* before label collection, following the hybrid retrieval
literature (Lin & Ma, 2021; Luan et al., 2021). Not tuned on eval labels.

## Reproducing the Evaluation

### 1. Keyword methods (no model needed)

```bash
pip install -r requirements.txt

# Regenerate all paper figures (reads from data/final/multi_query_results.json)
python scripts/generate_figures.py   # → docs/figures/ and data/final/figures/

# Full 5-query evaluation (Jaccard, TF-IDF, BM25 — no model required)
python analysis/multi_query_eval.py

# Single-query significance with Bonferroni correction
python analysis/significance.py

# Controlled arXiv experiment
python analysis/arxiv_experiment.py
```

### 2. Semantic scores for Q2–Q5 (requires model download ~90 MB)

```bash
# Downloads all-MiniLM-L6-v2 from HuggingFace on first run
python analysis/embed_queries.py

# Then re-run multi-query evaluation with full semantic results
python analysis/multi_query_eval.py
```

### 3. Full pipeline from scratch

```bash
# Re-scrape (respects rate limits, ~hours)
python crawler/<university>_scraper.py   # one per university
python data/merge.py                      # normalize schema

# Re-embed (requires model)
python embeddings/embed.py

# Re-run all analysis
python matcher/compare.py
python analysis/significance.py
python analysis/multi_query_eval.py
python analysis/arxiv_experiment.py
python analysis/ablation.py
python analysis/learn_to_rank.py
```

> **Overleaf:** Upload the contents of `docs/figures/` alongside
> `docs/research_paper.tex`. The LaTeX references `figures/ndcg_comparison.png`
> and `figures/umap_clusters.png` — both are generated by `scripts/generate_figures.py`.

> **Web explorer:** After regenerating any `data/final/*.json` file, run
> `python app/export_ui_data.py` to copy updated results into `app/data/`
> before reloading `app/index.html`. Then serve locally with
> `python app/run.py` (http://localhost:8080) — opening `index.html`
> directly via `file://` will fail due to browser fetch restrictions.

> **Note:** Scraper outputs are time-dependent (faculty pages change).
> The 768-professor corpus in `data/final/all_professors.json` reflects
> April–May 2026 scraping. arXiv paper IDs are similarly time-stamped.

## Adding a New University

```
1. Write crawler/<name>_scraper.py
   Output format: data/processed/<name>_professors.json
   Schema: name, university, research_text, biography, research_interests, ...

2. python data/merge.py          # auto-discovers new file
3. python embeddings/embed.py    # re-embeds full corpus
4. python matcher/compare.py     # re-runs comparison
```

## Limitations

- **Corpus coverage:** 9 US public universities; excludes MIT, Stanford, CMU.
- **Single annotator:** 162 labels assigned by one person; no IAA measured.
- **Semantic Q2–Q5:** Requires local model run (`analysis/embed_queries.py`).
- **LTR underpowered:** 67 labels insufficient for reliable LambdaMART training.
- **Late fusion not implemented:** arXiv integration via text concatenation
  degrades retrieval; separate embedding towers are the correct architecture.
